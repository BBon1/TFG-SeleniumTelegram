# TFG-SeleniumTelegram
Repositorio público con el código de la herramienta desarrollada para el trabajo de fin de grado

Scraper con Selenium en Telegram
-------------------------------------------------------------------------------
Comprobaciones y pruebas de Selenium para conectarse con la aplicación de mensajería Telegram, poder obtener y almacenar los mensajes y distintos ficheros que puedan surgir en los chats para después analizarlos, investigarlos y sacar conclusiones al respecto. 

Objetivos / Alcance:

[V] Extraer mensajes y ficheros de conversaciones (usuarios/grupos/canales)

[V] Extraer datos de perfiles de usuarios, grupos y canales

[V] Guardar datos en la base de datos MongoDB (en texto puro)

[X] Extraer mensajes de chats secretos -> No hay chat secreto en la ver. Desktop

------ Opcional / Trabajos futuros

[ ] Almacenar datos multimedia en la base de datos MongoDB

[ ] Modelo de inteligencia artificial de análisis

[ ] Anonimizar datos personales
